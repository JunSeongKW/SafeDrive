LPWM 고정 vs Adapter
같은 장면에서 particle이 어떻게 달라졌는가?

둘 다 NAVSIM Stage1 적응 모델에서 출발했습니다. 완료된 Stage2의 0 → 2,353 → 4,707 update 저장 결과입니다. 현재 별도로 학습 중인 공개 LPWM 대조군과는 다른 비교입니다.

관찰: 8장면·512 particle의 최종 평균 중심 이동은 0.0847 px, 최대 0.3476 px입니다. 모든 이동은 1픽셀 미만이며, 고정 모델의 중심·크기·presence는 학습 전·중·후 동일합니다. 기준 해상도는 128×128입니다.

청록 원: 고정 / 분홍 +: Adapter. 같은 인덱스를 선으로 연결합니다. 이동량 ×1입니다. 위의 이미지에서 확인할 지점을 클릭하면 아래에서 같은 영역을 확대합니다.

점과 박스를 읽는 법

  • 64개 점: 현재 프레임 particle 중심. 같은 색은 같은 LPWM 인덱스이며, 객체 종류나 객체 추적 ID를 뜻하지 않습니다.
  • 박스: 학습된 공간 범위(중심·크기)입니다. 검출기의 객체 정답 박스가 아닙니다. 고정 모델의 presence 상위 16개 인덱스를 양쪽과 세 시점에 동일 적용했습니다.
  • 투명도: presence 값에 비례하며 planning 중요도 점수가 아닙니다. 선택을 끄면 낮은 presence도 선명하게 볼 수 있습니다.
  • 원본은 실제 128×128 모델 입력을 확대했습니다. 미래 GT 없이 관측 4프레임에서 얻은 현재 particle입니다. FP32 단일 장면 진단 snapshot이며 BF16 배치 평가와 구분합니다.

Adapter 조건에는 명령 FiLM 학습과 SSL 유지 손실도 포함됩니다. 이 그림만으로 planning loss 단독 효과나 객체 정보·미래 feature 개선을 판단할 수 없습니다. 투영 객체 겹침은 가림의 대리 분류이며 실제 가림을 보장하지 않습니다. 8장면은 학습 전 고정한 선택을 전부 표시했습니다.
